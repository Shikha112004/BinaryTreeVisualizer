# Binary Tree Visualizer

An interactive Binary Tree Visualizer built using **C++** and **SFML**. The application allows users to perform common binary tree operations while visualizing the tree structure in real time through a graphical interface.

## Features

- 🌳 Insert Node
- 🗑️ Delete Node
- 🔍 Search Node
- 🔄 Reset Tree
- 📋 Inorder Traversal
- 📋 Preorder Traversal
- 📋 Postorder Traversal
- 🎨 Dynamic Tree Visualization

## Tech Stack

- C++
- SFML 3.0
- CMake

## Project Structure

```text
BinaryTreeVisualizer/
```

## How to Run

```bash
mkdir build
cd build
cmake ..
cmake --build .
./BinaryTreeVisualizer
```
